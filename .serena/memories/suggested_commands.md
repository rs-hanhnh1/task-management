# Suggested Commands
## Running the application
- `npm run dev`: Start the development server on localhost:3000
- `npm run build`: Build the application for production
- `npm run start`: Start the production server

## Code Quality
- `npm run lint`: Run ESLint to check for code quality and style issues

## Database (Prisma)
- `npx prisma generate`: Generate Prisma Client after schema changes
- `npx prisma db push`: Push schema changes to the database
- `npx prisma studio`: Open Prisma Studio to view and edit data

## System Utilities
- `find . -name "*.tsx"`: Find React component files
- `grep -r "pattern" .`: Search for patterns in files
- `git status`, `git diff`, `git log`: View git status, changes, and history
